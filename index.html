What it does
Everything you need.
⏱

Sub-millisecond timing

Hybrid sleep + spin-wait playback engine hits timing targets within 0.1ms regardless of system load.

◎

Dry-run preview

See exactly where every click will land before committing. A transparent overlay flashes ripples on screen.

⟳

Loop & chain

Run a macro up to 20× with a configurable delay between loops. Chain multiple macros into a sequence.

✂

Timeline editor

Drag events to adjust timing, delete individual events, edit click coordinates — all without re-recording.

⇱

Relative coordinates

Record positions relative to a chosen anchor so macros work even when the target window has moved.

🔍

Image anchoring

Use OpenCV template matching to find UI elements on screen and auto-correct click positions at playback time.

⚡

Conditional branching

Insert pixel-colour or template-match conditions that pause playback if the screen state doesn't match.

🪟

Window guard

Bind a macro to a window title — playback skips loops automatically if that window isn't in focus.

⚠

Panic key

Shift+Esc kills playback instantly and suppresses all output for 2 seconds — a hard brake if things go wrong.
